Transaction PIN (TPIN)

Set a 6-digit PIN to authorise all trades

What is a TPIN?

Your Transaction PIN is a separate 6-digit security code used exclusively to authorise trades — similar to how Zerodha's CDSL TPIN works. It is stored as a secure hash and never in plain text. You must enter it before every buy or sell order.

Never share your TPIN with anyone. TradeSecure will never ask for it via email, SMS, or phone.
